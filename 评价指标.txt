+------+--------------------------+--------------------------------------+----------------------------------------------------------+----------------------------------------------------------+
| 序号 | 指标名称                  | 衡量什么                             | 怎么计算                                                                                     | 为什么这样设计                                                                       |

| 1    | 运输距离                    | 箱区到泊位的                      | 对每个分配组，计算其分到箱区到对应泊位的距离，                      | 避免人为规定“多远算差”，用本次实际方案中的距离范围       |
|       | transport_distance    |运输距离是否合理。             | 按箱量加权平均；再用实际分配箱区中最近/最远箱区                     | 做相对评价；越靠近泊位越好。                                               |
|       |                                  |                                           | 作为相对基准评分。                                     

| 2    | 需求满足度                | 箱组需求是否被完整满足。  | 对每个原始箱组计算 assigned / demand，并额外奖励                  | 既关注总体分配了多少，也关注箱组是否被完整满足，              |
|       | demand_satisfaction|                                           | 完整满足；公式为 0.7 * 满足比例 + 0.3 * 是否整组满足，               | 避免只满足一部分却看起来比例还不错。                                 |
|       |                                  |                                           | 再按需求量加权。                                       

| 3    | 业务分散与集中程度   | 同一船舶的箱组分布            | 目标箱区数为 2 * 岸桥数量；实际箱区数少 1 或多 1                       | 防止同一船舶箱组过度集中导致作业冲突，也防止过度分散       |
|       | business_dispersion  | 到箱区的数量是否合适。     | 可接受，多 2 也可接受；少 2 或多 3 及以上为 0 分；                     | 导致运输和管理成本上升。                                                      |
|       |                                  |                                           | 公式为 10 - 2 * abs(实际箱区数 - 目标箱区数)，          
|       |                                  |                                           | 超出容忍范围归 0。                                     

| 4    | 峰值错峰程度              | 同一箱区内进箱。               | 对每个箱区计算进箱/出箱时间序列，先算重叠度 overlap，             | 进出箱高峰重叠会造成箱区拥堵；该指标鼓励进出作业在         |
|       | area_peak_staggering| 和出箱高峰是否错开           | 再算进出峰值时间差 peak_gap；公式为                                          | 时间上错开，提高现场作业顺畅度。                                      |
|       |                                   |                                           | 10 * (0.7 * (1 - overlap) + 0.3 * min(peak_gap / 2, 1))，
|       |                                   |                                           | 最后按作业量加权。                                    

| 5    | 贝位利用率                 | 本次新增分配是否紧凑，     | 只看本次新增分配，不纳入历史占用；总分为                                    | 防止为了一个贝中出现多个分配组随意混放导致后续翻箱概率增大；     |
|       | bay_utilization           | 并且一个贝是否                  | 10 * (0.6 * utilization_score + 0.4 * purity_score)。                        | 同时鼓励整贝使用、尾箱同尺寸合并，提高后续作业清晰度和执行效率。   |
|       |                                   |尽量只服务一个分配组。      | 利用率看启用贝位是否接近满载；纯度看一个贝是否只放       
|       |                                   |                                           | 一个分配组；若混放，必须同尺寸且都是尾箱不足一贝才     
|       |                                   |                                           | 给分，否则给 0。                                     

总分说明
--------
总分 = 5 个指标得分之和
满分 = 50 分
每个指标满分 = 10 分

指标覆盖范围
------------
1. 距离效率
2. 需求完成度
3. 船舶箱区分布合理性
4. 时间作业冲突
5. 贝位层面的紧凑性与作业纯度
